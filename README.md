# CONDUCTIVITY
Conductivity is a free locally hosted task manager. The core concept is built around the priority matrix, a dashboard to visually manage tasks based on color and location.

## FEATURES
There are four primary workzones tags in conductivity:
00 - Sticky Notes
01 - Priority Matrix
02 - Marble Jar
03 - Focus & Notes

## USAGE
A task usually starts with a sticky note, just an idea. The idea becomes a task when there's enough room to prioritize and a task becomes a marble when it's completed. Each marble has its own memory and lessons attached to it that can be reviewed later. 

## Tech Stack
Conductivity is built on pure HTML, CSS, JS, and wrapped all up into an Electron Application for easy desktop usage.
